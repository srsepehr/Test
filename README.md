# کتابخانه ویدیو و پادکست

یک اپلیکیشن فرانت‌اند با Next.js و تایپ‌اسکریپت برای نمایش و مدیریت ویدیوها و پادکست‌ها. همه چیز به صورت نمایشی و بدون بک‌اند است و نشست کاربر و ویدیوهای اضافه‌شده در مرورگر ذخیره می‌شود.

## اجرا

```bash
npm install
npm run dev
```

### رفع خطاهای معمول بعد از کپی/کلون از گیت‌هاب

- بعد از منتقل کردن پروژه، پوشهٔ `node_modules` همراه کد جابه‌جا نمی‌شود؛ حتماً `npm install` یا `npm ci` را روی سیستم جدید اجرا کنید تا وابستگی‌ها نصب شوند.
- اگر ادیتور خطاهایی مثل «Cannot find module 'next'» یا «ESLint: Failed to load config» نشان می‌دهد، نصب یا بازنصب پکیج‌ها مشکل را برطرف می‌کند.
- فایل `.npmrc` موجود، رجیستری عمومی `https://registry.npmjs.org/` را تنظیم می‌کند تا دانلود بسته‌ها در محیط‌های جدید ساده‌تر باشد.

## قابلیت‌ها

- رابط دو زبانه (فارسی/انگلیسی) با ذخیره در localStorage و تغییر جهت متن بر اساس زبان
- تم تیره/روشن با تشخیص خودکار حالت سیستم و ترجیح کاربر
- پخش‌کننده React Player برای یوتیوب و فایل محلی به همراه دکمه دانلود با نوار پیشرفت
- صفحهٔ اختصاصی هر ویدیو با هوک، اطلاعات سخنران، بخش یادداشت‌ها و مسیر نمایش همه ویدیوهای یک سخنران
- انیمیشن بارگذاری سراسری هنگام جابه‌جایی صفحات یا تغییر زبان/تم

سپس مرورگر را روی `http://localhost:3000` باز کنید.

## قابلیت‌ها
- صفحه اصلی با جستجو و نمایش دسته‌بندی‌ها.
- ورود/ثبت‌نام نمایشی با شماره موبایل و کد یکبار مصرف فرضی.
- صفحه پروفایل برای افزودن ویدیو با لینک یوتیوب یا فایل محلی و نمایش ویدیوهای کاربر.
- رابط کاربری راست‌به‌چپ و متن‌های فارسی با Tailwind CSS.
